Password Strength Checker (Python)

A simple Python console application that checks the strength of a password based on common security rules.

**Features**
- Checks password length
- Verifies uppercase and lowercase letters
- Checks for numbers
- Detects special characters
- Classifies password as Weak, Medium, or Strong
** Concepts Used**
- Python strings
- Loops
- Conditions
- Functions

 How to Run
1. Clone the repository
2. Run the file using:
   ```bash
   python main.py
}
